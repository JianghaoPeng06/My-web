# JasperPeng 后台 · 使用说明

管理网站的小工具：写文章、改文章、给正文排版、换封面和插图、置顶、推荐权重；管理角色；换首页海报（图片或视频）。改完一键生成页面。
只在你自己的电脑上运行（只听本机 127.0.0.1），不会上网。
它放在网站仓库的 `tools/jp-admin/` 里，跟着网站一起推到 GitHub —— GitHub 上那份就是云端备份。别人能看到这些源代码，但改不了你的网站：后台只有在你自己电脑上打开时才会运行。

## 打开

- 双击桌面上的 **JasperPeng 后台** 图标（没有的话，双击这个文件夹里的「创建桌面图标.cmd」放一个）。
- 也可以直接双击这个文件夹里的「打开后台.cmd」。
- 会弹出一个独立的窗口（Edge 的应用模式，没有地址栏）。关掉窗口就行，后台服务两分钟后自己退出。

## 日常怎么用

1. **改文章**：左边列表点一篇 → 中间改 → 右边是实时预览（和网站上的文章页长得一样）→ 点「保存」（或按 Ctrl+S）。
2. **写新文章**：点「写新文章」→ 填标题、英文标题（文章地址会跟着自动生成，也可以点地址旁边的「按英文标题生成」）、导语 → 写正文 → 换封面 → 保存。
   **作者**在「基本信息」里，空着就是 JasperPeng；写过的作者名会出现在下拉提示里。
3. **置顶 / 推荐权重**：在列表里直接点星星（置顶）和五个小点（权重），马上生效；编辑页里也能改。
   **精选到顶部栏**：编辑页「基本信息」里的开关。打开后这篇出现在顶栏那个大分类下拉面板的右边一列（读者看不到开关本身）。顶栏里的名字空着就用标题，标题太长可以填个短名。每个大分类最多 5 项（角色板块已经有 4 个角色，只能再放 1 篇），满了要先在别的文章上关掉一个。
4. **全部改完**：点右上角「生成页面」→ 等十几秒 → 打开 **GitHub Desktop** → 写一句 Summary → Commit to main → Push origin。

## 角色

顶上点「角色」。

- 左边是全部角色，顺序就是角色页上缩略图的顺序，用 ↑ ↓ 调（马上生效）。
- 中间改：名字、角色地址（网址里 ?c= 后面那段）、年份、版本、「查看资源」按钮跳到哪、立绘，四种语言的地图、身份、年龄、性别、台词、简介。
- 名字是专有名词，四格一般都写一样的（或者只填简体）。
- 立绘建议用透明底的 PNG，透明会保留。
- 右边是预览，深色，和角色页一样。
- 被导航「原创角色」菜单引用的角色（现在是草莓酱、拉、祈、夏花）不能直接删，要先在 data.js 里去掉引用。改了地址，引用会自动跟着改。

## 首页海报

顶上点「首页海报」。

- **换图片**：拖一张图进去。有视频的时候，这张图就是「静止画面」（视频没播之前、低配设备、减少动态效果时显示）。
- **换视频**：拖一段 MP4 / WebM 进去（25MB 以内，Cloudflare 单个文件的上限）。默认会顺便把视频的最后一帧存成静止画面。
- **去掉视频，只用图片**：视频文件删掉，首页变回一张图。
- **图注**：海报右下角那行小字，四种语言，点「保存图注」（或 Ctrl+S）。
- 「电脑 16:9 / 手机 4:3」可以看网站会怎么裁。

## 正文怎么排

正文是一块一块的：段落、小标题、更小的标题、引用、列表、编号列表、图片、封面图、分隔线、HTML。

- 下面的按钮加一块；每块右上角可以上移、下移、在下面加一段、删掉。
- 按住每块左边的「⋮⋮」可以拖动换顺序。
- 把一大段带空行的文字粘贴进段落里，会自动拆成好几段。
- 「图片」块：选一张图就会存成「文章地址-2.jpg」这样的名字，放进对应板块的文件夹。
- 「封面图」块：显示这篇文章的封面。
- 「HTML」块：原样放进页面，想要特殊排版的时候用。

## 图片

- 自动缩到长边 2000 像素以内。带透明的存成 PNG（透明保留），其他存成 JPG。GIF 原样保存。
- 换下来的旧图直接删掉，不留副本。

## 安全

- 每次保存之前，`data.js` 都会先备份到 `backups/`（保留最近 50 份）。改坏了可以从里面拿回来。
- 保存时只改你动过的那一篇，其他内容一个字都不碰。没改的字段原样保留，所以 GitHub Desktop 里只会看到你真正改了的那几行。
- 删除文章：文章和它的封面、插图一起删掉，不留副本。被别处引用的文章不让删（会提示你先去掉引用）。

- 后台程序更新过（改了 server.mjs 或界面文件）会自己重启，开着的窗口也会自己刷新成新的；手上有没保存的改动时只提醒、不自动刷新。

## 备份、换电脑

**不用另外备份。** 后台就在网站仓库里，你在 GitHub Desktop 推送网站时，后台的改动也一起推上去了。
只有三样东西留在本机、不上传（写在仓库根目录的 `.gitignore` 里）：`config.json`（这台电脑的网站在哪）、运行记录 `*.log`、`backups/`（data.js 的自动备份）。它们都会自动生成。

**在另一台电脑上用**：
1. 装 Node.js（nodejs.org，下载 LTS 版，一路下一步）。
2. 用 GitHub Desktop 把网站 My-web 克隆下来（放哪都行）。
3. 打开网站文件夹里的 `toolsjp-admin`，双击「安装.cmd」。它会自己认出网站文件夹（就是往上两层），不用选；装完桌面上就有「JasperPeng 后台」图标。
   不想放桌面图标的话，直接双击「打开后台.cmd」也行，第一次会自己把 config.json 写好。

两台电脑都在用的时候：开始干活前先在 GitHub Desktop 里 **Fetch / Pull**，拿到另一台推上去的最新内容；干完推送。这样两边不会打架。
网站文件夹挪了位置也不用管，下次打开后台会自己重新认。

## 文件

| 文件 | 作用 |
|---|---|
| `server.mjs` | 后台服务（Node.js，不用装任何别的东西） |
| `public/` | 后台界面（app.js 文章、chars.js 角色、poster.js 首页海报） |
| `config.json` | 网站文件夹在哪（`site`）、用哪个端口（`port`，默认 5620）。自动生成，不上传 |
| `start.ps1`、`打开后台.cmd` | 启动器（没有 config.json 就自己写一个） |
| `install.ps1`、`安装.cmd` | 新电脑第一次用：检查 Node.js、放桌面图标 |
| `make-shortcut.ps1`、`创建桌面图标.cmd` | 在桌面放图标 |
| `backups/` | data.js 的自动备份（第一次保存后才出现），不上传 |
| `server.log`、`server-error.log` | 后台的运行记录，出问题时看这里，不上传 |
