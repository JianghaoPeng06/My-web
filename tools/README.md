# tools · 工具

这里放的是**管理网站用的工具**，不是网站本身。网站页面不会用到这里的任何文件，所以放在这里不会让网站变慢。

它们跟着网站仓库一起推到 GitHub，GitHub 上那份就是云端备份；换电脑时把网站克隆下来，工具就都在了。

| 文件夹 | 是什么 | 怎么用 |
|---|---|---|
| `jp-admin/` | **后台**：写文章、改文章、正文排版、换封面和插图、置顶 / 推荐权重 / 精选到顶部栏、管理角色、换首页海报，一键生成页面 | 双击桌面上的「JasperPeng 后台」图标。详细说明见 [`jp-admin/使用说明.md`](jp-admin/使用说明.md) |
| `design-spec/` | **设计规范原文件**（给 AI 看的那份）：颜色、字体、版面、圆角、组件、动效的全部规则和数值 | 用浏览器打开 `design-spec.html` 就能看。让 AI 改网站样式时，把它一起交给 AI |

## 换一台电脑

1. 装 **Node.js**（nodejs.org，下载 LTS 版，一路下一步）。后台要用它运行。
2. 用 **GitHub Desktop** 把网站 My-web 克隆下来，放哪都行。
3. 打开网站文件夹里的 `tools\jp-admin`，双击 **「安装.cmd」**。它会自己认出网站文件夹，装完桌面上就有「JasperPeng 后台」图标。

两台电脑轮流用的时候：开始干活前，先在 GitHub Desktop 里点 **Fetch origin**（有新内容就再点 **Pull**），拿到另一台推上去的最新版本；干完再推送。这样两边的改动不会打架。

## 要知道的几件事

- **这些文件是公开的**：GitHub 上能看到，也能通过网站地址打开（比如 jasperpeng.uk/tools/README.md）。但别人**改不了你的网站**：后台只在你自己电脑上运行，只有你能推送。搜索引擎不会收录这个文件夹（网站根目录的 `_headers` 里写了 noindex）。所以这里**不要放密码、密钥**。
- **有三样东西不上传**，只留在每台电脑上，都会自动生成（写在网站根目录的 `.gitignore` 里）：
  - `jp-admin/config.json`：这台电脑的网站文件夹在哪
  - `jp-admin/*.log`：后台的运行记录
  - `jp-admin/backups/`：`data.js` 的自动备份（每次保存前一份，留最近 50 份）
- **设计规范原文件和网站上的文章「JasperPeng 设计规范文档」是两份东西**：原文件给 AI 看，规则最全；文章给读者看，只留干货，还能点能拖。改了其中一份，另一份不会自动跟着改。
